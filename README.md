# Company Database
A relational database for managing employees, wages, customers and sales orders.

## Tables
- Departments
- Employees
- Wages
- Customers (Customer/Client types)
- Orders

## Files
- 01_Create_Tables.sql: Create the Database And All Tables
- 02_Insert_Data.sql: Sample data
- 03_queries.sql: JOIN GROUP BY & search queries

## Sample Queries
- Employees with their departments (JOIN)
- Employees count per department (GROUP BY)
- Total wages per department
- Total Sales per employee

MySQL, MySQL WorkBench
